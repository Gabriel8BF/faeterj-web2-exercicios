# Exercícios - Módulo 04: Next.js e Roteamento

Resolução dos exercícios de fixação do Módulo 4 da disciplina de Programação e Design para Web II.

## 🛠️ O que foi desenvolvido
1. **Rotas Simples:** Criação das rotas `/sobre` e `/contato` utilizando o sistema de pastas do App Router.
2. **Menu de Navegação:** Componente `Menu.tsx` usando `<Link>` do `next/link` para navegação SPA, injetado no `layout.tsx` raiz.
3. **Layout de Seção:** Um layout aninhado (`app/projetos/layout.tsx`) com largura máxima de 900px, afetando exclusivamente a rota de projetos.

## 🚀 Como executar
1. `npm install`
2. `npm run dev`
